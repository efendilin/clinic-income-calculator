# 西醫基層合理門診量・申報與利潤計算機

繁體中文網頁計算機，支援最多五位醫師的門診量、診察費申報點數、掛號費、薪酬及營運貢獻試算。

## 功能

- 依各醫師實際看診日數分別計算六段合理門診量。
- 比較新舊制；顯示每段人次與申報點數。
- 可切換原檔允許負加給與加給最低為零兩種薪酬模式。
- 另填共用營運成本，匯出完整 CSV 試算明細。
- 響應式桌面與手機介面，無外部套件，不傳送或保存輸入。

## 使用

直接開啟 `index.html`，或在目錄執行 `python -m http.server 8765`，瀏覽 `http://localhost:8765`。

GitHub Pages：Settings → Pages → Deploy from a branch → main / (root)。

## 計算範圍

一般地區專任醫師，一般門診「處方交付特約藥局調劑」情境。新制採計日數為實際日數與22日較小值，每日六段寬度為35、10、20、20、65、超出部分；點數為364、250、220、160、70、50。舊制比較採25日上限、30、10、20、20、70、超出部分。

薪酬＝每月牌費＋每節診費×節數＋業績加給。加給＝（人次−節數×每節門檻）×加給單價，可設定最低為零。營運貢獻＝診察費點數×預期點值＋掛號費收入−薪酬−另填成本。

未計入慢箋、山地離島、兒童加成、假日保障、護理人力加計、藥費、處置費、部分負擔、核刪與稅費。結果為營運貢獻，不等於完整淨利；點值須按適用分區及季度自行設定。
